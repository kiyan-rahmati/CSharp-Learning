# Lesson 03 Example Notes

The runnable demonstration for this topic is in `../Program.cs`.

## How to experiment

1. Run `dotnet run` from this lesson directory.
2. Change one value or statement.
3. Run again and record what changed.
4. Restore the original example, then attempt the practice task in `../Notes.md`.

**Topic:** Understand top-level statements, namespaces, using directives, and program entry.
