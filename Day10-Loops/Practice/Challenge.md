# Challenge — Loops

Build a small console program that uses **for, while, do-while, foreach, break, continue, nested loops** in a realistic scenario.

## Requirements
- Use the feature deliberately.
- Use descriptive names.
- Handle at least one invalid or boundary case.
- Display a useful result.
- Try two test cases and record expected output.

## Reflection
What changes if the application must handle much more data or additional requirements?
