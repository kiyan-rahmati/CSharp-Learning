# Lesson folder template

Every lesson is deliberately kept flat and independent:

- `Notes.md` — the full study notes, definitions, explanations, and examples.
- `Program.cs` — the lesson's runnable code.
- `LessonXX.csproj` — an independent .NET console project.
- `Summary.md` — review and self-assessment.

There are no extra `Examples/`, `Exercises/`, or nested topic folders by default. If a lesson later grows substantially, its structure can be expanded deliberately.
