# Example 06 — Arrays

## Goal
Experiment with a small C# idea while studying **fixed size, indexing, Length, traversal, multidimensional arrays**.

```csharp
string input = "42";
if (int.TryParse(input, out int value))
{
    Console.WriteLine(value * 2);
}
```
