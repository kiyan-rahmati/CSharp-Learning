# Lesson 07 Practice

## Challenge
Create a calculator that supports four operations and handles division by zero.

## Requirements
- Write the solution yourself.
- Use meaningful names.
- Handle at least one edge case.
- Run the program and verify its output.

## Self-check
- [ ] I planned the solution before coding.
- [ ] I can explain every line I wrote.
- [ ] I tested normal and edge cases.
- [ ] I can improve the code without breaking it.
