# Common errors — Introduction to C# and .NET

## Frequent mistakes
- Misunderstanding the behavior of the feature.
- Forgetting a boundary case.
- Trusting input without validating it.
- Combining too many operations into one statement.
- Copying an example without adapting it.

## Topic reminders
C# language, compiler, .NET SDK/runtime, console projects, program entry point

## Diagnosis
Read the first useful error, locate the line, inspect values, reduce the problem to a minimal example, make one change, and retest normal and edge cases.
