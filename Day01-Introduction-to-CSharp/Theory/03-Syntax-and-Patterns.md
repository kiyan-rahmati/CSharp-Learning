# Syntax and patterns — Introduction to C# and .NET

## Readability checklist
- Use descriptive names.
- Keep statements focused.
- Validate assumptions.
- Use braces for multi-line logic.
- Comment on intent, not obvious syntax.

## Practice
Write a minimal example and then improve its readability without changing behavior.
