# Study Guide

## Suggested lesson routine (45–90 minutes)

1. **Read (10–20 min):** Read the lesson Notes.md carefully. Highlight unfamiliar vocabulary.
2. **Predict (5 min):** Read the runnable Program.cs and predict its behavior.
3. **Run (5 min):** Run `dotnet run` from the lesson directory.
4. **Rebuild (15–25 min):** Type the example yourself rather than copy/paste.
5. **Experiment (10 min):** Change inputs and test edge cases.
6. **Practice (15–30 min):** Complete Practice.md without looking for a solution.
7. **Review (5 min):** Use Summary.md and update PROGRESS.md.

## Principles

- Learn the why, not only the syntax.
- Avoid skipping ahead when a prerequisite is unclear.
- Use small commits with descriptive messages.
- Keep your own notebook for deeper explanations and questions.
- When stuck, reduce the problem to the smallest reproducible example.
- For APIs, verify behavior in the official Microsoft documentation.

## Completion standard

A lesson is complete when you can explain the core concept in your own words, run and modify the example, complete its practice, and handle at least one edge case.
