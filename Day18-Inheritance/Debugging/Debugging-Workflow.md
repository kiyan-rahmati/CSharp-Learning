# Debugging workflow

1. Reproduce the problem reliably.
2. Read the first useful error message.
3. Inspect variables and program state.
4. Isolate the smallest failing code.
5. Change one thing and rerun.
6. Verify both the normal path and an edge case.

In VS Code, use breakpoints, Step Over, Step Into, Variables, Watch, and Call Stack. Debugging is evidence-based; avoid guessing.
