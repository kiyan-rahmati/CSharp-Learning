# Exercises — Async and Await

## Warm-up
1. Write a minimal example demonstrating this lesson.
2. Explain each line in your own words.
3. Change one value and predict the result before running.

## Practice
4. Create a small scenario using: Task, Task<T>, async, await, cancellation, asynchronous I/O.
5. Add a validation rule.
6. Test a normal case and an edge case.
7. Refactor repeated logic into a clear step or method.

## Challenge
8. Combine this lesson with an earlier concept to build a small console feature.
