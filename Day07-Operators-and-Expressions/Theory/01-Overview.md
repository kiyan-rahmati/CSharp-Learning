# Day 07 — Operators and Expressions

## Learning outcomes
Understand the purpose of **Operators and Expressions** and use it in a small C# console program.

## Topic map
precedence, associativity, ternary, compound assignment, expression design

## Study workflow
1. Read the core concepts and syntax notes.
2. Review all eight examples.
3. Run the project with `dotnet run`.
4. Attempt the exercises without opening solutions.
5. Test one normal case and one edge case.

## Self-check
- Explain the idea in your own words.
- Write a small example without copying.
- Identify a common mistake.
- Describe when the feature is useful.
