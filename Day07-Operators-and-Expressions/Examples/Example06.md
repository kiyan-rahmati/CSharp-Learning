# Example 06 — Operators and Expressions

## Goal
Experiment with a small C# idea while studying **precedence, associativity, ternary, compound assignment, expression design**.

```csharp
string input = "42";
if (int.TryParse(input, out int value))
{
    Console.WriteLine(value * 2);
}
```

## Try it
- Change a value or input.
- Predict the output before running.
- Add a validation or boundary case.
