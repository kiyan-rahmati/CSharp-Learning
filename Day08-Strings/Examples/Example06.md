# Example 06 — Strings

## Goal
Experiment with a small C# idea while studying **interpolation, immutability, search, replace, split, trim, formatting**.

```csharp
string input = "42";
if (int.TryParse(input, out int value))
{
    Console.WriteLine(value * 2);
}
```

## Try it
- Change a value or input.
- Predict the output before running.
