# Lesson 11 Practice

## Challenge
Print a multiplication table and validate user input in a loop.

## Requirements
- Write the solution yourself.
- Use meaningful names.
- Handle at least one edge case.
- Run the program and verify its output.

## Self-check
- [ ] I planned the solution before coding.
