# CSharp Learning Journey

A structured, Persian-friendly learning repository for C# and .NET, progressing from language fundamentals to algorithms, data structures, object-oriented design, and a final project.

## Repository structure

- `01-...` through `36-...`: one independent topic per lesson.
- Each lesson contains a `Notes.md` study guide and a runnable C# console project.
- `ROADMAP.md`: the complete course plan.
- `PROGRESS.md`: lesson completion tracker.
- `.github/workflows/dotnet.yml`: build check for pushes and pull requests.

## Technology

- C#
- .NET 10
- .NET CLI
- Git and GitHub

## Working with a lesson

Open a lesson folder and run:

```bash
dotnet run
```

Build the complete solution from the repository root:

```bash
dotnet build CSharp-Learning-Journey.sln
```

## Learning approach

Each lesson is developed progressively: concepts, clear explanations, examples, exercises, review, and practical implementation. A lesson is marked complete only after its concepts and exercises have been reviewed.

> The lesson folders are scaffolds. Detailed notes and exercises will be written as each lesson is taught.
