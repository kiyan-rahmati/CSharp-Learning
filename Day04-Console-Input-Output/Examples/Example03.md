# Example 03 — Console Input and Output

## Goal
Experiment with a small C# idea while studying **Console.Write, WriteLine, ReadLine, parsing, validation**.

```csharp
int x = 12;
int y = 5;
Console.WriteLine($"Result: {x + y}");
```

## Try it
