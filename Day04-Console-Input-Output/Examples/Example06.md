# Example 06 — Console Input and Output

## Goal
Experiment with a small C# idea while studying **Console.Write, WriteLine, ReadLine, parsing, validation**.

```csharp
string input = "42";
if (int.TryParse(input, out int value))
{
    Console.WriteLine(value * 2);
}
```

## Try it
- Change a value or input.
- Predict the output before running.
- Add a validation or boundary case.
