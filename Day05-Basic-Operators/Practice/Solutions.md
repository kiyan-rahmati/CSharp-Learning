# Solution guidance — Basic Operators

This file gives a process, not one mandatory implementation.

1. Start with the smallest working example.
2. Reuse the relevant example files as reference.
3. Keep the main flow readable.
4. Validate assumptions and include an edge case.
5. Run at least two test values.

## Review questions
- Which part demonstrates the lesson?
- What input/state does the program assume?
- What happens at the boundary?
- Can the code be simplified?
