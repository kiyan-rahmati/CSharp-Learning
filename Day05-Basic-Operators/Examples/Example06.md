# Example 06 — Basic Operators

## Goal
Experiment with a small C# idea while studying **arithmetic, comparison, logical, assignment, modulo, precedence**.

```csharp
string input = "42";
if (int.TryParse(input, out int value))
{
    Console.WriteLine(value * 2);
}
```
