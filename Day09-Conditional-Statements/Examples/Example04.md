# Example 04 — Conditional Statements

## Goal
Experiment with a small C# idea while studying **if, else, switch, switch expression, pattern matching, guard clauses**.

```csharp
bool isReady = true;
Console.WriteLine(isReady ? "Ready" : "Not ready");
```

## Try it
- Change a value or input.
- Predict the output before running.
- Add a validation or boundary case.
