# Example 03 — Scope and Parameters

## Goal
Experiment with a small C# idea while studying **local scope, blocks, parameters, ref, out, optional parameters**.

```csharp
int x = 12;
int y = 5;
Console.WriteLine($"Result: {x + y}");
```

## Try it
- Change a value or input.
- Predict the output before running.
- Add a validation or boundary case.
