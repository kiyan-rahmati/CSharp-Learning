# Example 04 — Debugging Fundamentals

## Goal
Experiment with a small C# idea while studying **breakpoints, step controls, watch, call stack, error diagnosis**.

```csharp
bool isReady = true;
Console.WriteLine(isReady ? "Ready" : "Not ready");
```

## Try it
- Change a value or input.
- Predict the output before running.
- Add a validation or boundary case.
